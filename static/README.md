# Quanto prometer no app?

Previsão do tempo de entrega de 197 mil pedidos reais do DoorDash e escolha do prazo mostrado ao cliente: LightGBM quantílico + conformal prediction, recalibrado a cada hora.

Escolha a meta de pontualidade e compare os métodos, ou veja pedidos reais da semana de teste com o prazo que o app mostraria.
